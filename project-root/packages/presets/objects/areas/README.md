# Area Presets

Use Area presets when the node should feel like a place with arrival prose, POIs, or a manageable exit list.

## Available Presets

### one_room_shack

Small enclosed shelter or interior.

### dead_end_nook

Short optional stop that rewards inspection and then turns back.

### street_corner

Junction-like place where several routes meet but the node still deserves authored presence.

## Rule Of Thumb

If the exit list starts carrying too much traversal logic, consider inserting a Gate or Path fixture instead of overloading the Area.
