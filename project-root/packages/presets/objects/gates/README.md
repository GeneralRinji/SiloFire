# Gate Presets

Use Gate presets when the threshold itself matters visually or mechanically.

## Available Presets

### billboard_business_door

Public-facing business threshold with visible introduction.

### service_entrance

Lower-ceremony side or back entrance for staff, alley, or delivery access.

### locked_civic_door

Official blocked threshold that surfaces institutional closure or denial.

## Rule Of Thumb

If the story beat is about trying a threshold, seeing it, or being blocked by it, start with a Gate preset.
