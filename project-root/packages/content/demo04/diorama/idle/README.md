# demo04 idle sketch

This folder is reserved for future reusable idle behavior fragments and examples.

Current intent:

- `idle` means ambient actor behavior during explicit inactivity or waiting
- `banter` is a separate later system and should not be mixed into early idle rules
- idle output may be `shared`, `personal`, or `symptom` depending on the authored behavior

The first rollout should focus on:

- one stationary resident with contextual idle modes
- one outdoor walker with route-based ambient presence
- no during-play conversational banter yet
