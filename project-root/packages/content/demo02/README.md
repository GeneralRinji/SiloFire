# demo02

This project is the same playable demo content as `demo`, but organized for human browsing instead of by schema type.

## Folder Intent

- `entry/`: title screen, first approach, and the lead-in route into Shack Run
- `shack_run/`: the main harbor shacks segment, including local thresholds and side stops
- `harbor_road/`: the road out toward harbor proper and its dead-end destination
- `endings/`: the short and long ending routes plus their destination nodes
- `fixtures/`: support examples and nested-discovery fixture content

## Important Rule

Folder names are organizational only.

Node identity still comes from front matter `id`, and authored references still point to node ids, not paths.

## Why This Exists

This version is meant to be easier to read as a folder tree while hand-authoring without a dedicated editor.
